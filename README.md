# MyIULMS

An unofficial Android student portal client for IULMS, built with Kotlin and Jetpack Compose.

## Features

- Secure IULMS login
- Encrypted Remember Me
- Exam results
- GPA overview and calculated academic insights
- Outstanding fee vouchers
- Transcript and CGPA
- Light and dark themes
- Iqra University inspired UI
- Automatic session re-login

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- OkHttp
- Jsoup
- Kotlin Coroutines
- EncryptedSharedPreferences

## Disclaimer

This is an unofficial student project and is not an official application of Iqra University.
